# 170C 腰腿运动学（LowerBody）

交付给部署 / 运控接入的解析正逆解库。不含 CAN、规划与驱动。

版本 **1.0.0**

## 交付内容

```
LowerBody/
├── include/LowerBody.h      # 对外接口
├── src/LowerBody.cpp        # 实现
├── cmake/                   # find_package 配置
├── examples/
│   ├── self_test.cpp        # 接入前自检（必须通过）
│   └── traj_print.cpp       # 轨迹抽帧打印
├── CMakeLists.txt
└── README.md
```

## 单位

| 量 | 单位 |
|--|--|
| 关节角、欧拉角 | **rad** |
| 位置、杆长 | **m** |

库内不做度 / 毫米换算。`traj_print` 仅在打印时把位置乘 1000 显示为 mm。

## 坐标系与零位

基座固连在脚踝：

- **+Z**：站立朝上
- **+X**：前方（点头使 Q2 沿 +X 偏移）
- **+Y**：左

零位：五轴电机角全 0，小腿、大腿、腰偏置均沿 **+Z**。

```
脚踝 -- L1 --> 膝盖 -- L2 --> 髋 -- d2 --> Q2
  −Y           −Y         −Y      pitch: +Y
                                  roll:  +X
                                  yaw:   +Z
```

TCP 位置不是 Q2 法兰的世界坐标，而是：

```
p_tcp = p_hip + ( d2·sin(pitch),  0,  d2·(cos(pitch)−1) )
R_tcp = Ry(pitch) Rx(roll) Rz(yaw)
```

因此零位站立时 `p_tcp = (0, 0, L1+L2)`。Q2 法兰实际位置 = `p_tcp + (0, 0, d2)`。

## 关节定义

`Joints5` 顺序固定：

| 下标 | 枚举 | 电机 | 轴 |
|--|--|--|--|
| 0 | `LowerBody::Ankle` | 脚踝 | 基座 −Y |
| 1 | `LowerBody::Knee` | 膝盖 | 基座 −Y |
| 2 | `LowerBody::Hip` | 共用髋 | 基座 −Y |
| 3 | `LowerBody::WaistRoll` | 腰侧倾 | 基座 +X |
| 4 | `LowerBody::WaistYaw` | 腰回转 | 基座 +Z |

腿三电机正转 = `Ry(−q)`：`q > 0` 弯向 **−X**（下蹲）。

髋电机与腰 pitch 共用一根 −Y 轴：

```
q_leg_hip = −q_ankle − q_knee     # 使髋姿态为单位阵
q_hip     = q_leg_hip − q_pitch   # 下发给电机的第 3 轴
```

直接写关节角时必须满足上述关系，否则几何点头与电机角会对不上。走笛卡尔接口（`Inverse_Kinematics*`）则已处理。

腰姿态：`R = Ry(pitch) Rx(roll) Rz(yaw)`。侧倾不要接近 ±π/2。

## TCP 位姿

与 `T3_leg` 相同：`[x, y, z, rx, ry, rz]`，旋转 `R = Rz(rz) Ry(ry) Rx(rx)`（ZYX）。

注意：位姿里的 `ry` 不是腰 pitch，`rz` 也不是腰 yaw。要电机角请走逆解，不要把欧拉角直接当关节角。

## 几何参数

默认（可在构造时覆盖）：

| 参数 | 默认 | 含义 |
|--|--|--|
| `L1` | 0.270 m | 小腿 |
| `L2` | 0.400 m | 大腿 |
| `d2` | 0.110 m | 腰 Q1–Q2 偏置 |

```cpp
LowerBody::Params p;
p.L1 = 0.270;
p.L2 = 0.400;
p.d2 = 0.110;
LowerBody kin(p);
```

## 接入示例

```cpp
#include "LowerBody.h"

LowerBody kin;

LowerBody::Joints5 q;
q << 0.6, -1.2, 0.8, 0.1, 0.2;   // rad

LowerBody::Pose6 pose = kin.Forward_Kinematics_Pose(q);  // [x,y,z,rx,ry,rz]
Eigen::Matrix4d T = kin.Forward_Kinematics(q);

LowerBody::Joints5 q_ik = kin.Inverse_Kinematics_Pose(pose);
if (!LowerBody::Reachable(q_ik)) {
    // 目标超出二连杆工作空间，不要下发
}
```

笛卡尔直线：对位姿做位置线性插值 + 姿态 slerp，每帧调用 `Inverse_Kinematics`。本库不提供规划。

## 不可达

腿目标距离不在 `[|L1−L2|, L1+L2]` 内时，逆解脚踝 / 膝盖 / 髋为 **NaN**。请用 `LowerBody::Reachable(q)` 判断，不可达则不要下发电机。

## 部署注意

1. 本库只给出几何角，限速、限位、碰撞由运控负责。
2. 膝盖解选取弯向 −X 的那一支（下蹲构型），不返回另一支。
3. 点头补偿已包含在 FK/IK 中：逆解时从目标位置减去 `(cx, 0, cz)` 再解腿，接入时不要再减一遍。
4. 实物杆长与默认值不一致时，必须改 `Params`，不要改公式。
