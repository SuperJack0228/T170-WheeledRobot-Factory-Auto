# ti5-agv-seer（仙工 AGV 底盘 SDK）

安装后桌面会出现文件夹 **ti5-agv-seer**（中文桌面为「桌面」），内含头文件 `Ti5_Seer.hpp` 与本说明。系统路径：`/opt/ti5-agv-seer/`。

仙工（SEER）Robokit **TCP 协议**底盘控制客户端。主类：`Seer`。无 C++ 命名空间。对外只认这一份头文件。

返回约定：`0` 成功，`>0` 机器人 `ret_code`，`<0` SDK 错误。不含辊筒 / 顶升 / 货叉等外设封装。

默认连状态 `19204`、控制 `19205`、导航 `19206`；配置 `19207`、外设 `19210` 按需连接。

## 路径

| 路径 | 内容 |
|------|------|
| `/opt/ti5-agv-seer/include/Ti5_Seer.hpp` | 公开头文件 |
| `/opt/ti5-agv-seer/lib/libseer.so` | 动态库 |

## 在自己的程序里用

需要 **C++17**。

```cpp
#include "Ti5_Seer.hpp"

Seer robot("192.168.90.194");
if (!robot.Connect()) return 1;

double x, y, angle;
std::string cur, last;
robot.GetLocation(x, y, angle, cur, last);

robot.SetSpeed(0.05, 0.0, 0.0);
robot.Stop();

robot.NavigateToStation("AP25");
robot.Disconnect();
```

```bash
g++ -std=c++17 \
  -I/opt/ti5-agv-seer/include \
  -L/opt/ti5-agv-seer/lib \
  -Wl,-rpath,/opt/ti5-agv-seer/lib \
  -o demo demo.cpp \
  -lseer -lpthread
```

### 常用接口（节选）

| 类别 | 方法 |
|------|------|
| 状态 | `GetLocation` / `GetSpeed` / `GetBlocked` / `GetBattery` / `GetNavStatus` / `GetRelocStatus` / `GetIo` / `GetAlarm` / `GetRobotInfo` |
| 运动 | `SetSpeed` / `Stop` / `Translate` / `Turn` / `SoftEstop` |
| 导航 | `GoToStation` / `NavigateToStation` / `PauseNav` / `ResumeNav` / `CancelNav` |
| 重定位 | `Relocate` / `DoRelocate` / `WaitRelocateReady` |
| 音频 / IO | `PlayAudio` / `PauseAudio` / `StopAudio` / `QueryIo` / `SetDo` / `SetRelay` |
| 规划前 | `GetStations` / `GetTargetPathStations` / `GetPathBetweenStations` / `GetMapInfo` / `GetAreaIds` / `DownloadMapData` |

完整声明见头文件。原始应答可用 `LastBody()`。
