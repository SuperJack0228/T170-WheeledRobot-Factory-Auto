Dispatch

调度

手动由你排顺序。自动去等待点，听工厂调度系统发来的任务。

自动调度监控

手动

上料：料盘抓毛坯，再放到传送带一。转运：传送带一按检测框窗口抓，再放到传送带二。下料：传送带二抓成品，再放到料盘二。这里不向调度申请。

    当前没有编排在跑。

    自动

    和命令行里的 dispatch 相同。到等待点后听调度。上料：料盘抓完、去传送带一时申请放置，超时就直接放。转运：不申请，检测框中心落在码系窗口内才抓，有件才去传送带二并申请放置。下料：传送带二只申请一次再抓，然后放到成品盘。放置申请超时都是直接放。顶部「停止」只中止当前动作；离开调度请点「退出调度」。调试充电在「动作」页。

    退出调度会中止动作、断开与调度系统的等待，并结束调度模式；监控里「调度中」应变为未进入。
