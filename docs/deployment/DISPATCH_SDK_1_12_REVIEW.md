## 接口与行为

SDK 接口为 std::string report_exception(const std::string &message)。SDK 的 AreaException、RobotException 及异常码参数已退出应用适配层。本机 ERR_* 字符串继续用于网页状态和诊断，不作为 SDK 异常码发送。

| SDK 返回 | 应用处理 |
|---|---|
| RETRY | 从当前异常对应的重试位置继续：重新拍照、重新抓放或重新检查硬件；不是默认认为故障已经修好 |
| SKIP | 结束当前任务且不发送 DONE，保持当前位置和夹爪状态，等待下一条任务 |
| OFFLINE | 结束当前任务且不发送 DONE，退出调度并关闭连接，不自动回 Home、导航或补发电机使能 |
| 空字符串 | 视为说明无效、发送失败或断线，原地停止，不重试、不执行新任务；本机停止／退出请求可结束该等待 |
| 非约定字符串／SDK 调用异常 | 按上报失败处理，日志记录原始结果，不当作重试 |

地图是进入调度的前置条件。地图更新／重定位失败时，RETRY 循环重试；SKIP 取消本次进入调度，OFFLINE 退出；两者都不会带着无效地图执行任务。上报失败则原地等待本机退出请求。

## 原提交已正确适配的部分

- Client、SDK 适配器及测试替身使用文字参数和字符串返回值。
- 上料、传送带抓取、传送带放置、转运和下料的多数异常分支已把三类操作结果向上传递，不再用 bool 混合“已解决／未解决”。

## 本轮补齐

1. 操作结果优先于任务类别恢复。充电路径同样先处理 SKIP／OFFLINE／上报失败，避免先执行回 Home 或导航。
2. 夹爪掉线进入新的人工选择接口；其他已上报的故障也保留明确的文字描述。电机故障选择 RETRY 后只清除历史 IO 故障闩锁，允许重新检测；不清除停止请求，不跳过后续硬件检查。
3. 地图准备返回完整操作结果，替换 bool 折叠；反复 RETRY 使用循环，避免递归累积。
4. 调用阻塞 SDK 前先更新网页错误说明、当前活动及 pending 状态；增加 exception_wait 耗时和决策日志。
5. 空白描述不进入 SDK；SDK 异常、空返回和未知返回按失败停住；调用前后都检查停止请求，迟到的 RETRY 不覆盖中止。
6. OFFLINE、上报失败及停止退出时不在析构清理中额外使能身体电机。
7. 同步日志文案，不再把 RETRY 写成“已解决”，也不再打印已移除的 SDK 异常码。
8. 区分任务执行中的 CAN 故障与主动停止：两者原先都可能返回 −4。存在 CAN 故障且没有本机停止请求时，进入异常交互；真正的停止请求仍优先退出。

## No.120 最短测试步骤

先将本批修改提交推送到 deployment1117。120 已使用源码时，停止主程序和网页，在原源码目录执行：

```bash
conda activate human_interaction_env
./deploy/update_dev.sh
./deploy/run_maintenance.sh
```

另开终端在相同目录执行 ./deploy/run_web.sh，打开原网页地址，选择 No.120，手动进入调度。机器人需安装与这套接口匹配的 SDK 1.12 头文件和动态库；本轮不需要重新建档或迁移标定。

联调优先检查：

1. 正常任务仍能执行，成功后才收到完成反馈。
2. 进入一个可控的视觉异常后，网页先显示说明，机器人停止等待；选择 RETRY 后重新识别并继续。
3. 在尚未持件时选择 SKIP，确认没有 DONE、没有额外回 Home 或导航，下一条任务正常进入。
4. 选择 OFFLINE，确认网页退出调度，机器人没有额外动作，维护入口可继续使用。
5. 异常等待时断开调度连接，确认不自行重试或接受新任务；退出后保存 field_logs 当天记录。

SKIP 不包含自动卸下已持工件的善后策略。若手里已有工件，先按现场工艺处理，不能仅凭“任务已跳过”推定夹爪已空；本轮首次联调不要把这种情况直接接入无人任务队列。

## SDK 阻塞与本机停止的边界

report_exception 本身会阻塞到操作选择或断线。当前应用在 SDK 调用前后检查本机停止标志，可以保证 SDK 返回后不会因迟到的 RETRY 再动作；不能据此声称网页退出能立即打断正在阻塞的 SDK 调用。

若等待过程中按网页“退出调度”，应同时在调度端选择 OFFLINE，或使 SDK 检测到断线后返回，再确认本机退出。需要完全由本机即时取消该等待时，SDK 应提供明确的 cancel／disconnect 接口及并发调用约定；本轮不通过分离线程或强制释放正在调用的 SDK 对象来伪造即时退出。
