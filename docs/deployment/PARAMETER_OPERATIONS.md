# 参数编辑与应用

日常仅编辑当前机器人的 `config/robots/编号/quick_params.yaml`，或在网页维护模式的参数页保存。其他模型、相机或视觉 YAML 仍可按其职责编辑。完整来源说明见 [配置来源](CONFIGURATION.md)。

## 常用操作

```bash
# 编辑后统一应用；不启动机器人或运动
./deploy/apply_config.sh

# 仅校验，下次维护/生产启动读取
./deploy/apply_config.sh --validate-only

# 查询参数归属，源码环境中使用
python tools/parameter_index.py head_grasp.grasp_z_offset_m
```

命令会区分三种结果：已保存并热更新；已保存但需要等待空闲/重启；校验失败。不能热更新的资源改动会在下一次启动 `maintenance` 或生产入口时加载，不会被临时文件覆盖。

## 读写与回滚

网页、终端应用及档案切换使用工作区文件锁，防止两次保存相互覆盖。候选配置在独立目录校验，主程序按“硬件事务锁 → 配置锁”提交；合法候选才替换运行快照和内存对象。无效网页修改恢复持久文件，运行配置保持上一份合法状态。网络中断导致应用结果未确认时，保留持久值和候选，不宣称应用成功。

编辑器通常不参与文件锁。手工编辑完成后再执行应用；应用期间检测到来源发生变化会拒绝本次候选，避免混合版本。修改未被当前 deployment 引用的文件不会影响当前机器人。

## 相机与单机档案

新机默认使用头、左右手相机理论值，No.124 当前参考保留。相机文件、机型或模型改变时统一应用会提示重启；新的四份抓放参考按当前文件指纹重新建立。理论值的光学轴和 SDK 法兰转换由生成器负责，不能在调用端再重复旋转或转换一次。
