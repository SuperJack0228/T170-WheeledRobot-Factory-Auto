# 各种设备 ArUco 编码方案

- 日期：2026-11-04
- 需求原文（不改）：[各种设备编码方案.txt](各种设备编码方案.txt)
- 坐标系与双码贴法对齐：`aruco/board_pair6cm_aruco`（平贴 / 贴墙）
- 旧试验工程（`board_yf100_aruco` 五码、`board_hdm100_aruco` 八码、`board_belt_aruco`、`board_pair6cm_aruco` 的 500–507）**只作几何参考，量产 ID 以本文为准，旧工程不改。**

后续改编码先改本文，并在文末「修订记录」补一行。

## 1. 原则

托盘和固定目标用同一套思路：**定位段 × 信息段**。看见的号落在哪一段，就知道它是定位还是信息；两段拼起来才是这只东西的编号。

- **托盘**：四码，对角相同。定位 `100–199`，信息 `0–99`。编号映回 QR。方案见 §5、§6，**本修订不改**。
- **固定目标**：两码一组，左定位、右信息。每只独占一个编号，用来查这台机床的参数（偏置、台号、入料/出料口）。三族各一段：
  - `500–599` 圆方（本期：传送带，每台一条）
  - `600–699` 海德曼（本期：传送门，每台两扇，一扇一个号）
  - `700–799` 放置料架（每台机床附近一只）
- AGV 负责走到站位。码负责 6D，并用编号选定参数。参数表不写进本文。

| 对象 | 现场数量 | 每目标贴码 | ArUco 回答什么 | 编号 |
|------|----------|------------|----------------|------|
| 圆方传送带 | 10 | 2（左定位、右信息） | 编号 + 6D | 族内 `n`，查机床参数 |
| 海德曼传送门 | 100 扇 | 每扇 2 | 编号 + 6D | 族内 `n`，查该扇参数 |
| 放置料架 | 60 | 2（左定位、右信息） | 编号 + 6D | 族内 `n`，查机床参数 |
| 圆方托盘 | QR `0001`–`2999` | 4（对角两两相同） | 盘号 + 6D | 映回 QR |
| 海德曼托盘 | QR `3000`–`5999` | 4（对角两两相同） | 盘号 + 6D | 映回 QR |

同框两扇海德曼门是两组不同的号。按心距各自配对，定位和信息不要交叉。

## 2. 号段（`DICT_5X5_1000`）

```
000–099   托盘信息          100 个
100–199   托盘定位          100 个     → 100×100 = 10000（本期 5999 够用）
200–499   备用

500–549   圆方定位           50 个
550–599   圆方信息           50 个     → 50×50 = 2500
600–649   海德曼定位         50 个
650–699   海德曼信息         50 个     → 50×50 = 2500
700–749   放置料架定位       50 个
750–799   放置料架信息       50 个     → 50×50 = 2500

800–999   备用
```

每段内部都是前一半定位、后一半信息。托盘的「一半」是 100 个号，三族固定目标的「一半」是 50 个号。

禁止交叉：

- `0–99` 只作托盘信息，不上固定目标。
- `100–199` 只作托盘定位，不上固定目标。
- 定位段只贴在左（或托盘的 A、C），信息段只贴在右（或托盘的 B、D）。
- 圆方、海德曼、放置料架三段互不混用。备用段未启用前不印。

### 2.1 三族固定目标

和托盘一样，先把一个定位号配完该族全部信息号，再用下一个定位号。信息宽度 `W = 50`。

```
pose_id = P + (n - 1) // 50
info_id = I + (n - 1) % 50
n       = (pose_id - P) * 50 + (info_id - I) + 1
```

| 族 | 业务前缀 | 定位起点 `P` | 信息起点 `I` | `n` |
|----|----------|--------------|--------------|-----|
| 圆方 | `YF` | 500 | 550 | 1–2500 |
| 海德曼 | `HDM` | 600 | 650 | 1–2500 |
| 放置料架 | `RACK` | 700 | 750 | 1–2500 |

左码 = `pose_id`，右码 = `info_id`。两枚都进 PnP。`n` 从 1 连续占用，不跳号。未登记的 `n` 只上报「未注册编号」，不套用别的机床参数。

### 2.2 托盘

对角 AC = 定位（同一 ID，`100–199`），BD = 信息（同一 ID，`0–99`）。  
先用定位 **100** 配信息 **0–99** 编满 100 只，再用定位 **101** 配 **0–99**，以此类推。公式和展开表见 §6。圆方 / 海德曼共用这一池，盘种仍看 QR 号段。

## 3. 统一约定

### 3.1 坐标系

与 `board_pair6cm_aruco` 一致。

- 相机（人眼，可低头）：**右下前**（+X 右、+Y 下、+Z 前）。170C 为 D435，230C 为 D456。
- 所有目标自身系：**前左上**（+X 前、+Y 左、+Z 上）。双码组原点在两码心连线中点。托盘原点在对角线交点。

平贴（圆方传送带、放置料架、托盘）：

```
             前 (+X)  码标注方向
左(+Y)   左·定位      原点        右·信息   右(−Y)
             上 (+Z)  朝天
```

贴墙（海德曼传送门，条带横贴、标注朝天）：

```
             上 (+Z)  标注朝天
左(+Y)   左·定位      原点        右·信息   右(−Y)
             前 (+X)  进墙（人看墙的方向）
```

码的「上」（图案标注）平贴时朝目标前方，贴墙时朝天。

固定目标：**左码必须落在该族定位段，右码必须落在该族信息段**。定位段数值整体小于信息段，所以仍然是左小右大。贴反会绕 Z 转 180°，抓放偏置全反；左右段对调则报警，不要自行把 +Y 翻过去。传送带 / 门 / 料架没有托盘那种 0°/180° 对称，**不要**对它们做 yaw 折半。

### 3.2 字典与尺寸

量产只用 **`DICT_5X5_1000`**。打印、检测、培训只备一种格子。

整贴按等宽格：5 格数据 + 左右各 1 格黑边 + 左右各 1 格白边，共 9 格。白边、黑边、数据格同宽，都是外框 / 9。黑框（检测边）= 外框 × 7/9。不要把 7/9 收成 0.78。换 4×4、6×6 时仍是黑边 1 格、白边 1 格，只改外框和总格数（4×4 为 8 格、黑框 6/8；6×6 为 10 格、黑框 8/10）。

| 现场 | 距离 | 外框（含白边） | 每格 = 白边每侧 | 黑框 |
|------|------|----------------|-----------------|------|
| 圆方传送带（170C / D435） | 约 60–70 cm | **30 mm** | 3.333 mm | 23.333 mm |
| 放置料架，圆方侧（170C / D435） | 约 60–70 cm | **60 mm** | 6.667 mm | 46.667 mm |
| 圆方托盘（170C / D435） | 约 60–70 cm | **40 mm** | 4.444 mm | 31.111 mm |
| 海德曼传送门（230C / D456） | 约 80–140 cm | **60 mm** | 6.667 mm | 46.667 mm |
| 放置料架，海德曼侧（230C / D456） | 约 80–140 cm | **60 mm** | 6.667 mm | 46.667 mm |
| 海德曼托盘（230C / D456） | 约 80–140 cm | **40 mm** | 4.444 mm | 31.111 mm |

表内毫米数是外框/9 与外框×7/9 四舍五入到 0.001 mm，以分数为准。

同框靠 **ID 段** 区分托盘 / 圆方 / 海德曼 / 放置料架，并区分定位和信息。不要用 `detectInvertedMarker` 兼检正反色。海德曼若常在 **1.4 m + 1280 宽**，每格大约 4.4 px，偏紧：230C 尽量用 1920，批量印前在 140 cm 实拍 6 cm 5×5。

## 4. 固定目标（传送带 / 传送门 / 放置料架）

### 4.1 本期编号

按台号从小到大占 `n`。海德曼同一台的两扇门各占一个连续号，左右顺序在台账里定死，之后不要对调。原先全厂共用的料架种类对（502/503、506/507）取消，放置点改在 `700–799` 按只编号。具体台号与 `n` 的对照另表维护，编码只保证公式。

圆方传送带，平贴，30 mm。10 条都落在定位 **500**：

| n | 业务 ID | 左定位 | 右信息 |
|---|--------|--------|--------|
| 1 | `YF-0001` | 500 | 550 |
| 2 | `YF-0002` | 500 | 551 |
| 10 | `YF-0010` | 500 | 559 |
| 11–2500 | 预留 | 500 / 560 起 | |

海德曼传送门，贴墙，60 mm。前 50 扇用定位 **600**，后 50 扇用定位 **601**：

| n | 业务 ID | 左定位 | 右信息 |
|---|---------|--------|--------|
| 1 | `HDM-0001` | 600 | 650 |
| 2 | `HDM-0002` | 600 | 651 |
| 50 | `HDM-0050` | 600 | 699 |
| 51 | `HDM-0051` | 601 | 650 |
| 100 | `HDM-0100` | 601 | 699 |
| 101–2500 | 预留 | 602 / 650 起 | |

放置料架，平贴，60 mm。前 50 只用定位 **700**，第 51–60 只用定位 **701**：

| n | 业务 ID | 左定位 | 右信息 |
|---|---------|--------|--------|
| 1 | `RACK-0001` | 700 | 750 |
| 50 | `RACK-0050` | 700 | 799 |
| 51 | `RACK-0051` | 701 | 750 |
| 60 | `RACK-0060` | 701 | 759 |
| 61–2500 | 预留 | 701 / 760 起 | |

### 4.2 怎么解

进入 PnP 的点是已检出码的 **四角**（*n* 枚 → *4n* 点）。两枚都看见时 8 点，比单码稳。先按心距把同一组的左、右配成对，再代入 §2.1。

| 看见 | 能做 | 不能做 |
|------|------|--------|
| 左定位 + 右信息（同一族） | 稳 6D + 族内编号 | 未注册的 `n` 不套参数 |
| 只剩左或只剩右 | 单码 6D（较弱） | 编号不全，不查参数 |
| 左右段对调 | 报警，不输出业务 pose | — |
| 一枚缺角 | 那一枚整颗无效 | 靠剩下那枚 |
| 两族的码，或两组目标 | 各自独立配对 | 不要交叉配 |

`min_markers = 1` 仅作兜底。对外报编号要定位、信息各至少 1 枚。心距现场定（参考：皮带试验 109 mm，平贴组 486 mm，贴墙组 211 mm）。编码不依赖心距。一台海德曼两扇门是 **两组独立 PnP**，不是四码一块板。

### 4.3 打印

每只印一对，不要多只共用一对：`5x5-{pose_id}` → 左，`5x5-{info_id}` → 右。

| 业务 | 本期套数 | 号从哪到哪 |
|------|----------|------------|
| `YF-0001`–`YF-0010` | 10 | 500 + 550–559 |
| `HDM-0001`–`HDM-0100` | 100 | 600 + 650–699，601 + 650–699 |
| `RACK-0001`–`RACK-0060` | 60 | 700 + 750–799，701 + 750–759 |

预留 `n` **先不要印**。建议另表字段：`family, n, biz_id, pose_id, info_id, print_mm, mount, robot`。这张表不进托盘的 `qr_aruco_map.csv`。

## 5. 托盘：对角定位码 + 信息码

本节与修订前一致。

### 5.1 顶点与贴法

俯视，从 **右下角** 起 **逆时针** 记 A→B→C→D：

```
              前 (+X)  无把手
     C 左上 ●─────────────● B 右上
            │  定位 AC     │
            │    ╲     ╱   │      BD = 信息码（两枚同一 ID）
            │      ╳       │      AC = 定位码（两枚同一 ID）
            │    ╱     ╲   │
     D 左下 ●─────────────● A 右下
              后 (−X)  无把手
     左(+Y) 把手                 右(−Y) 把手
```

- A、C 贴 **同一张定位码**（`100–199`）。
- B、D 贴 **同一张信息码**（`0–99`）。
- 对角相同，邻边不应相同。

把手在左右、前后无把手：水平面绕竖直轴转 **0° 或 180°** 时，约定输出 **同一个** 托盘 FLU。

### 5.2 位姿怎么取唯一值

原点：矩形对角线交点（与盘几何中心不一致时用示教偏置）。

- +Z：出盘面、朝天。
- +Y：沿把手轴（左右）。
- +X：沿无把手轴（前后），右手系。

解出后若与规范相差 180°（绕 Z），乘 `Rz(180°)`，yaw 落到 **[0°, 180°)**。身份只看定位段 + 信息段，不依赖哪一角是 A。

### 5.3 至少看见什么

| 看见 | 能做 | 不能做 |
|------|------|--------|
| 1 枚定位 + 1 枚信息 | 盘号 + 粗 6D | 几何弱，建议再靠近拍 |
| 2 枚定位（对角） | 稳 6D，盘号未知 | 缺信息码时不能映 QR |
| 2 枚信息 | 四角仍可解 6D | 无定位段，盘号不全 |
| 4 枚全在 | 盘号 + 稳 6D（16 个角点） | — |

推荐：`min_pose_markers ≥ 1` 且 `min_info_markers ≥ 1` 才对外报盘号。PnP 仍只用已检出码的四角。

## 6. QR ↔ ArUco 对照（一一对应）

业务盘号 = QR 四位数字。圆方 `0001–2999`、海德曼 `3000–5999` 走同一套 100×100，不按机床分号。

```
n        = QR                         # 0001 → 1
pose_id  = 100 + (n - 1) // 100       # 100..159（本期用到 159）
info_id  = (n - 1) % 100              # 0..99
```

逆变换：

```
QR = (pose_id - 100) * 100 + info_id + 1
```

只允许 `100–199` 配 `0–99`。其它组合丢掉。`160–199` 是池内剩余（还可再编约 4000 只），第三类盘或超 6000 只时再用，不要提前印。

按定位号成块展开：

| 托盘顺序 | QR | 定位 AC | 信息 BD |
|----------|-----|---------|---------|
| 第 1–100 只 | 0001–0100 | **100** | 0–99 |
| 第 101–200 只 | 0101–0200 | **101** | 0–99 |
| 第 201–300 只 | 0201–0300 | **102** | 0–99 |
| … | … | 103、104… | 0–99 |
| 第 5901–5999 只 | 5901–5999 | **159** | 0–98 |

### 6.1 样例（抽检用）

| QR | 类型 | 定位 AC | 信息 BD | 业务 ID |
|----|------|---------|---------|---------|
| 0001 | 圆方 | 100 | 0 | TRAY-0001 |
| 0002 | 圆方 | 100 | 1 | TRAY-0002 |
| 0100 | 圆方 | 100 | 99 | TRAY-0100 |
| 0101 | 圆方 | 101 | 0 | TRAY-0101 |
| 2999 | 圆方 | 129 | 98 | TRAY-2999 |
| 3000 | 海德曼 | 129 | 99 | TRAY-3000 |
| 3001 | 海德曼 | 130 | 0 | TRAY-3001 |
| 5999 | 海德曼 | 159 | 98 | TRAY-5999 |

建议表字段：`map_version, qr, tray_type, dictionary, pose_id, info_id, print_mm, robot`。本版 **`map_version = 6`**（v1–v5 未量产）。托盘公式本次未改，已印盘仍按 v6 查。

### 6.2 打印清单

托盘：`5x5-{pose_id}` ×2 → A、C；`5x5-{info_id}` ×2 → B、D。圆方、海德曼托盘都是 40 mm，白边与数据格等宽（见 §3.2）。同一 `(pose, info)` 只对应一只 QR。

固定目标的打印见 §4.3。

## 9. 扩容怎么加

1. **同一族加数量**：`n` 往后连续编。一个定位号的 50 个信息号用完，再用下一个定位号。加印新的一对，不要复用已有号。
2. **某一族超过 2500**：从 `800–999` 或 `200–499` 再切一段「前一半定位、后一半信息」，并升一版对照。不要挤托盘的 `0–199`。
3. **第四类固定目标**：用下一段备用号，仍是前一半定位、后一半信息。不要塞进这三族的号。
4. **托盘超过 6000 / 需要第三类盘**：先用满 `pose 160–199`（池内还可再编约 4000 只，总共 10000）；再改对照表版本。已印的盘按旧 `map_version` 查。
5. 固定目标保持两码（左定位、右信息）。托盘保持四码对角。两套贴纸不要互换。
6. 机床参数挂在族内 `n` 上。站位仍由 AGV 任务给出。

## 10. 检测与误读

1. 只开 `DICT_5X5_1000`。分流：
   - `0–99` 托盘信息，`100–199` 托盘定位
   - `500–549` / `550–599` 圆方定位 / 信息
   - `600–649` / `650–699` 海德曼定位 / 信息
   - `700–749` / `750–799` 放置料架定位 / 信息
   - 其余当未启用
2. 固定目标：同一组左码在定位段、右码在信息段，且两段属于同一族，再算 `n`。
3. 只看见半对：可以出单码 pose，编号标为未知，不查机床参数。
4. `n` 超出本期已登记范围：按「未注册编号」上报，保留 pose 供排查，不套用已登记参数。
5. 托盘两枚都在定位段、无信息段：只报 pose。两个不同定位 ID：丢弃。同一信息 ID 出现三次以上：叠盘或误检，丢弃。
6. 重投影过大（建议先 2 px）的那一枚不进 PnP。
7. 单码缺一个角：这一枚无效。

## 11. 第一期落地顺序

1. 托盘仍按 §6 生成 `qr_aruco_map.csv`（`map_version=6`）。固定目标按 §4.1 另表，预留 `n` 不印。
2. 圆方：先贴 1 条带 `YF-0001`（左 500 / 右 550）+ 1 只料架 `RACK-0001`（左 700 / 右 750）+ 2 只样盘（QR 0001、0002），170C 核对 FLU 与编号。
3. 海德曼：先贴 1 扇门 `HDM-0001`（左 600 / 右 650）+ 1 只料架 + 2 只样盘（QR 3000、3001），230C 核对贴墙前左上、1.4 m、盘 0°/180°。
