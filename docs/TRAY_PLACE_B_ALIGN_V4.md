# 料盘放置V4：B点观察、邻孔仿射定位、对准后放下

基线3731df2，2026-11-05。本轮本地修改，未实机验收。取代放置下降过程中持续定位、接近遮挡区再锁定的默认方式；抓取算法、调度协议保持。

## 执行链路

1. 头相机仍负责分配目标行列号、粗XY和网格朝向。伸手过程中预备手相机，但不运行邻孔修正。
2. 料盘放置的SDK伸手段执行到原B点轨迹末点，保持放置姿态，不再提前从B前的减速区交接。原有抓取保留平滑交接。
3. 从B末点关节接入原局部IK/PD执行器，Z参考保持在B，仅调整XY；编码器仍可跟随到B。使用RGB邻孔观测反复确认对准，未定位时不会自动下降20mm，也不会因原1.5秒无观测预算就立刻失败。
4. 目标连续3帧满足放置XY容差4mm、目标稳定及末端速度条件，且实测高度在B附近10mm内，才锁定基座XY。B观察总预算默认6秒，是超时上限，不是固定等待。失败保留持件状态，禁止松爪。
5. 锁定后不再索取新视觉结果、不再重新选择孔号。保持原姿态与已锁定XY，按原加减速/末段速度协调下降至固定C参考；邻孔消失不会单独导致失败。跟随、中止及固定C高度边界仍有效。
6. 沿用现有放置完成/松爪确认及双手完成判断；松爪失败保留状态。完成后调用已有两阶段撤离：竖直抬离，再回固定关节中转位。双手各自完成B观察与下放，沿用原有双手松爪门控，并非新增强制同步下降屏障。

## 高度来源

定位准备时先将头相机anchors的Z替换为现有工位tray_z_ref_now()，再拟合粗平面；盘面采用当前工厂水平料盘假设，头相机只保留粗XY/yaw，不再把其Z/倾斜作为几何真值。之后按原腰部姿态变换到当前手臂基座。孔口参考高度来自tray.z_ref_m和tray.z_ref_waist_z_m及当前腰高，不等于TCP终点C。

左右left_place/right_place仍使用已有放置参考像素与reference_height_m。geometry模式按工位孔口平面和相机/工具关系计算B高度下的期望像素，不直接把C高度的十字原封不动搬到B。此换算仍依赖相机内参、手眼和工位高度；若实际放置轴线的参考示教错误，本补丁无法凭空推断正确十字。未伪造新的单机像素标定。

## 邻孔定位

- 不检测手相机ArUco、不读取深度、不用YOLO框中心代替孔心。头相机的孔号不可在一次会话中改变。
- 粗网格投影只引导邻孔ROI；目标孔始终排除。先展开ROI、提取灰度孔边或橙色盘面孔环。占用位置只允许橙色盘面孔环，不接受凸起金属零件边缘。
- 圆环筛选使用拟合椭圆的归一化残差，允许粗尺度/朝向不准时出现合理椭圆，随后用网格联合验证。保留完整度和尺寸范围，以免夹爪/残弧成为孔。
- 四个以上且分布不近似共线时，RANSAC拟合二维仿射，解释平移、旋转、缩放和剪切。点少或近共线时采用参数更少的相似变换；不会硬求不受约束的仿射。
- 至少60%且不少于最小数量的候选共同支持模型；限制缩放、旋转、各向异性、目标相对初始孔号的偏移及外推距离。最后仍用真实图像重投影残差检查。没有把旧3mm平移门限简单调大。
- 用拟合后的图像映射直接计算隐藏目标孔心。不从拟合结果恢复新的机器人Z或姿态。下一帧重新用实际相机位姿及原始网格估计绝对映射，上一帧只用于搜索ROI，避免把相对偏移无限累计。

## 外置配置

`visual_servo.tray_place` 新参数：

| 参数 | 默认值 | 用途 |
|---|---:|---|
| observe_at_B | true | B点保持高度观察/对准 |
| observe_timeout_s | 6 | B观察与修正的总预算 |
| affine_enabled | true | 图像仿射/相似配准 |
| association_gate_m | 0.030 | 初始邻孔搜索范围，仍小于半孔距，非到位容差 |
| affine_min_scale / affine_max_scale | 0.65 / 1.5 | 合理图像尺度范围 |
| affine_max_rotation_rad | 0.35 | 图像配准旋转范围，非手腕命令 |
| max_extrapolation_pitches | 2.5 | 目标离可见孔支持区域的外推上限 |

旧place_lock_height_m、place_visibility_floor_m仍用于关闭B模式后的连续下降路径。固定C、松爪参数及撤离参数沿用原配置。本轮没有调整抓取PD或把放置容差放宽成抓取容差。

## 调试证据

原CSV及会话参数/目标/模型快照保留，新增配置也写入快照。

- handoff.reason=place_stop_at_B：SDK伸手段结束于B。
- place_B_observe：开始固定高度观察；control.phase为acquiring/aligning，reason=place_B_observe_align_XY。
- tray_neighbor_model：模型名、共同支持数、缩放、图像旋转、拟合误差及外推距离；vision_source为neighbor_affine或neighbor_similarity。
- place_XY_locked：已确认XY，进入不依赖新视觉的下放。
- ready_place_locked：C附近完成，后续才进行原有松爪门控。
- place_B_alignment_timeout：观察预算内没有完成可靠对准，不能当成“到底后松爪失败”。

观察处理依然只有一个左右公平轮询线程；不要求视觉与电机同频。没有默认增加存图或同步磁盘写入。

## 本地检查与限制

保留原15项离线检查并增加现有用例的覆盖：B无观测保持、未对准不下降、高于旧锁定高度仍可锁定、锁定后丢视觉完成下放、B超时不盲降；双手延迟观测/松爪就绪；仿射外点、共线降级、偏置深度/yaw下的图像定位及相机XY运动；参数与快照往返。

从11/05日志抽取的40组被旧模型拒绝的候选对应点，重放新生产拟合函数后35组接纳、5组因孔号偏移预算保留拒绝。不是原始RGB重放，也不是35次实机放置成功。相机真实反光、孔环遮挡、B点视野、参考像素和持件偏心仍需现场验证；本机macOS不能链接执行Linux/ARM64机器人SDK。

## 现场验证

```sh
cmake -S . -B build_robot
cmake --build build_robot -j4
./build_robot/t170_factory 2>&1 | tee startup-tray-place-v4.log
```

仍用原料盘放置指令，先确认到B后Z确实保持、XY有小幅修正，再看到place_XY_locked，随后连续下降、松爪、上抬、关节返回。回传完整startup日志、CSV和会话快照，异常时附同轮B点RGB。固定工位盘面高度和放置轴线参考应与当前机器一致；不得只凭离线通过写成可无人值守发布。
