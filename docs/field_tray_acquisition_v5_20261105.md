# 料盘放置：孔环发现、行列对应和观察恢复（V5）

修改日期2026-11-06，现场资料为11/05。基于 `74e564f` 的本地修改。范围是料盘放置视觉定位、一次有界观察恢复和调试记录；调度协议不变。算法已做离线验证，实机放置成功率、碰撞余量和机器人端耗时仍需现场验证。

## 动作链路

1. 双手到B点，姿态固定，保持高度。
2. 各手独立在料盘粗范围整体发现橙色孔环，不以每个孔的小预测窗口作为首次检测入口。
3. 根据已知网格提出平移/相似变换假设，做一对一匹配，使用RANSAC精修相似/仿射模型。
4. 比较不同的行列解释。可见盘边提供“孔不能在真实料盘外”的辅助信息；同时用拍摄时的TCP状态和现有像素映射，排除超出原有TCP可修正范围的候选，不会先锁住一个控制器永远拒绝的邻孔。不识别手相机二维码，不要求头相机提供准确深度。
5. 首次对应明确后，在校正后的小ROI里继续做透视校正和孔环精修，驱动原来的XY伺服。
6. 连续稳定对准后锁定XY，关闭新的视觉修正，按原固定C高度下放、松爪、抬升。

图像模型的修正量与机械臂的实际移动量是两回事。`global_search_m` 限制图像注册搜索，原来的 `max_correction_m` 继续约束TCP实际XY修正。不会因为找到一个偏得较远的图像模型，就让机械臂直接移动相同的距离。

## 定位恢复与少孔

- 连续局部定位失败后，重新执行整体发现和对应，不会永久围绕错误初始投影重复搜索。
- 未找到目标，或锁定前失去目标超过1.2秒：停止沿旧目标继续修XY，只向上恢复一次，最大20mm、速度上限25mm/s。重新找准后下放到原C。总观察预算仍为6秒，不无限重试。
- 多个分布良好的邻孔：仿射模型。稀疏/共线的两个对应点：相似模型。
- 两个完整孔环加两个方向的可见盘边，或原有TCP可修正范围能唯一排除其他行列解释时，可以支持较大初始偏差的初始化；没有足够身份信息时仍需换观察视野。
- 一个邻孔只能短时更新已经确认的模型平移：最多4帧、距上次多孔观测0.6秒、单次6mm、累计10mm。不用一个孔从零猜行列。
- 没有新孔环不会产生新的有效视觉观测。已经锁定后，可以按既有流程完成最后的遮挡下放。

## 满盘与部分遮挡

已放置位置仍可用露出的橙色盘面孔环。金属工件顶面不作为盘面孔的几何观测。

部分橙色孔环采用已知半径范围、外边缘颜色方向和角度覆盖约束做圆弧拟合；不是把C形色块直接拟合成一个完整椭圆。当前至少覆盖7/16个角度分区。短弧证据不足时拒绝使用。

盘边检测适用于当前深色料盘和浅色背景。它只使用图中可见、具有持续明暗分界、与料盘轴方向相容的有限线段，不假设未配置的料盘外形尺寸，也不把线段无限延长。换夹具/背景可关闭 `boundary_enabled`。没有盘边或其他足够证据时，重复网格可能确实无法唯一确定行列，恢复观察比强行选择更可靠。

## 关键外置参数

位于 `config/move_box_params.yaml` → `visual_servo.tray_place`，全部进入实机配置快照。

| 参数 | 当前值 | 含义 |
|---|---:|---|
| `global_acquisition` | true | 首次/丢失后的整体发现与对应 |
| `boundary_enabled` | true | 当前深色盘/浅背景盘边辅助 |
| `global_search_m` | 0.090 | 目标位置处图像模型修正搜索上限，允许超过一个孔距；不是TCP位移 |
| `global_match_gate_m` | 0.009 | 提出对应的粗门限；最终评分使用RANSAC共识门限 |
| `global_ambiguity_margin` | 0.75 | 最优与其他行列解释的支持分差；完整孔权重1，残差扣分，部分弧权重0.65；不是毫米 |
| `global_max_hypotheses` | 4000 | 搜索计算预算；耗尽时不把未比较完的结果当作唯一解 |
| `reacquire_after_frames` | 2 | 连续局部失败后重定位；失败全局搜索也隔帧重试 |
| `partial_rims` / `partial_min_bins` | true / 7 | 受约束部分孔环 |
| `single_neighbor_max_frames` | 4 | 单孔先验跟踪最长帧数 |
| `single_neighbor_max_age_s` | 0.6 | 距上次多孔有效观测的最大时间 |
| `observe_recovery_lift_m` | 0.020 | 一次观察抬升；设0可关闭抬升 |
| `observe_recovery_after_s` | 1.2 | 初次无目标或锁定前丢失后的等待时间 |
| `save_debug_images` | true | 本轮验证保存；正式连续运行可改false |
| `debug_image_period_s` | 0.25 | 每手采样存图间隔 |

## 新日志和回放数据

原CSV尾部追加：`tray_stage`、`tray_candidates`、`tray_global_hypotheses`、`tray_identity_margin`、`tray_rejected_distance`、`tray_rejected_target`、`tray_rejected_short`、`tray_occupied_used`、`tray_partial_used`。

- `acquiring`：整体发现/对应；`acquired_refining`：完成初始对应，进入局部精修；`tracking`：正常多孔跟踪；`sparse_tracking`：短时单孔平移跟踪。
- `tray_acquire_no_rims` / `insufficient_rims`：孔环候选不足。
- `tray_acquire_no_supported_grid`：找到了候选，但无法支持一个合理网格；详情区分拟合、背景和原有TCP修正范围拒绝数量。
- `tray_acquire_ambiguous_grid`：存在接近的其他行列解释。详情记录各方案目标偏移、支持数和评分。
- `tray_acquire_hypothesis_budget`：计算预算耗尽。
- `tray_target_outside_tcp_envelope`：局部精修后的目标也无法通过原有TCP可修正范围检查，转入重新定位；这没有增加新的机械臂位移限制。
- `place_observation_recovery`：开始一次观察抬升。
- `place_XY_locked`：可以进入固定XY下放；`ready_place_locked` 只是下降完成，完整任务还需 `gripper_end/open_confirmed` 和后撤完成。

`tray_candidates` 只在全局搜索帧统计；正常跟踪时为0不代表画面没有孔。`tray_skipped_occupied` 保留旧字段兼容，表示标为占用的位置数；实际使用数量看新字段 `tray_occupied_used`。

调试图在 `picture_debug/left_hand` 和 `picture_debug/right_hand`。紫色小圆表示整体发现的候选，青色/橙色预测圈表示空孔/占用孔，绿色是局部接受的孔心，红十字是预测目标，黄色圈是有效拟合目标。

每个采样帧生成三件套：

```text
place_s2_f521.jpg           # 叠加图
place_s2_f521.jpg.raw.png   # 与叠加图对应的原始RGB，左手已按运行约定旋转
place_s2_f521.jpg.yaml      # 对应内参、畸变、拍摄时相机/TCP位姿、任务参考/像素参数、料盘几何、行列和占用状态
```

写盘使用后台线程，每手最多一个待写帧，新帧覆盖尚未写出的旧调试帧，不积压录像。写盘错误会报告但不改变定位结果。图像新鲜度检查使用实际提交前的时间。

硬件无关回放工具（需要本地OpenCV和yaml-cpp）：

```bash
cmake -S . -B build_offline -DT170_SERVO_TESTS_ONLY=ON -DCMAKE_BUILD_TYPE=Release
cmake --build build_offline --target tray_localizer_replay -j4
./build_offline/tray_localizer_replay config/move_box_params.yaml picture_debug/right_hand/place_s2_f521.jpg.yaml
```

多个元数据文件按实际拍摄顺序作为后续参数传入，工具按手和会话分别保持定位状态。限频记录适合单帧定位回放，不是完整控制时序回放。

## 验证范围与现场关注点

离线新增检查覆盖：50/80mm初始投影偏差、重复网格歧义、盘边/TCP可执行范围消歧、两个孔加可见盘角或唯一可执行目标、不可执行目标拒绝、单孔跟踪期限、丢失后重定位、满盘孔环、半圈弧与短弧拒绝、左右手状态隔离；控制测试覆盖首次无目标与锁定前丢失的一次20mm抬升、上限约束、重新锁定及原C下放。

对11/05保存的左右首帧叠加JPEG，还进行了近似投影检查：根据图中青色预测圆重建粗投影，右手找到11个候选孔环并形成有效网格解释，左手找到12个候选。右手末帧的纯图像检查仍存在多个行列解释，不能把单张图的全局拟合当作始终可用的唯一定位来源；运行链路另外使用原有TCP范围约束和一次观察恢复。旧图缺少原始拍摄位姿/未叠加图，不能当作完整实机回放或放置精度证明；投影检查模式 `--projection` 为此独立标注。

若现场真正需要的XY修正超出现有 `max_correction_m`，或放置参考像素本身不正确，当前运行仍不能凭视觉拟合自行放宽运动范围或修复参考示教。日志会保留具体原因，便于区分定位问题与参考/执行参数问题。

机器人上使用原构建目录重新编译 `t170_factory`，再按现有入口启动。先观察双手普通位置，再看边角和接近满盘；对每轮同时检查“找到候选→对应明确→局部精修→锁定→松爪→抬升”。若失败，保留CSV、实机参数快照和上述图像三件套，以日志中的具体阶段判断，不再统一归因于“拟合失败”。
