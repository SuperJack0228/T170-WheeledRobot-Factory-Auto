## 料盘放置

动作仍为 B 点观察、保持高度对齐 XY、锁定后下放到固定 C、松爪、撤离。

首次网格定位原来始终要求至少两个完整孔环。现在增加部分环途径：

1. 每条部分环仍须通过原有孔径、外边缘、圆弧覆盖范围和拟合残差检查。
2. 当完整环少于两个时，匹配支持至少包含四个独立孔环，并且不能共线。支持中可以混合完整环与部分环。
3. 仍需通过已有网格身份歧义、盘边界、模型范围和可执行 TCP 修正范围检查。
4. 在不同且足够接近的拍照时刻，连续得到一致目标，才建立首次定位。重复处理同一张图不计数。
5. 跟踪建立后的部分环与短时单邻孔逻辑继续沿用原实现。

新参数位于 `visual_servo.tray_place`，会写入每次运行的配置快照：

```yaml
partial_acquire_min_neighbors: 4
partial_acquire_confirm_frames: 2
partial_acquire_stability_m: 0.004
```

这里的 4mm 是连续定位结果的一致性要求，不是最终放置误差门限。最终放置仍采用原有 `place_xy_accept_m` 等参数。

新增日志：

- `complete`、`partial`：最终候选的完整环、部分环支持数量。
- `partial_bootstrap`、`required_partial_support`：是否使用部分环首次定位以及支持要求。
- `partial_confirmations`：连续确认进度。
- `tray_acquire_partial_pending`：正在等待新帧确认，尚未授权修正。
- `tray_acquire_insufficient_support`：最终候选的参照数量或空间分布不足。
- `rejected_alternative_hint`：其他候选的拒绝提示，不能当成最终候选失败原因。
