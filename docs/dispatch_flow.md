# 调度模式：信号与动作流程

以当前代码为准（`orchestrator/cpp/robot_runtime.cpp`，库 `RobotClient` 1.8.0）。  
申请超时 **20 s**。任务结束后原地再听 **20 s**。传送带取帧、二维码或检测失败先自动再拍一次，仍失败才上报 `1201`，由网页决定再拍还是留下。料盘二维码失败直接上报 `1201`。

调度靠每 2 秒的位姿报文看位置：电量、x、y、角度、`current_point`（底盘当前站名）。

传送带抓放的视觉规则以本文 §2 为准。窗口数字在 C++ 常量里，改 yaml 不会改窗口，改完要重编并重启 `t170c_debug`。

---

## 1. 谁发给谁

### 1.1 调度下发，机器人收到后才动

| 收到 | 含义 | 机器人做什么 |
|------|------|----------------|
| `TASK_LOAD` | 上料 | 料架抓毛坯 → 上料点放置 |
| `TASK_TRANSFER` | 转运 | 传送带一抓半成品 → 传送带二放置 |
| `TASK_UNLOAD` | 下料 | 传送带二抓成品 → 成品盘放置 |
| `CHARGE` | 充电 | 回 home → 去充电点充到阈值 |
| `PLACE` | 允许放置 | 结束对应的放置申请，开始放 |
| `PICK_HALF` | 允许抓半成品 | 转运抓取不再等这条 |
| `PICK_WELL` | 允许抓成品 | 结束下料抓取申请，开始抓 |

任务报文里的点位才覆盖本机站点，收到新值才改，任务结束不清：

| 字段 | 用途 |
|------|------|
| `raw_material_point` | 上料料架 |
| `sequence_one` | 上料点 / 转运抓取点（传送带一） |
| `sequence_two` | 下料点 / 转运放置点（传送带二） |
| `well_done_point` | 成品盘 |
| `standby_point` | 无任务时的待命点；没有则用 yaml `dispatch_wait_station`（AP14） |
| `charge_point` | 充电点；没有则用 yaml `chassis.charge_station` |

四个工作点都空时，`apply_mission` 会先向调度要站点（`NEED_POINTS`），再等任务。未知任务字符串不执行，回 home → AP14。

### 1.2 机器人发给调度

| 发出 | 何时 |
|------|------|
| `APPLY_PLACE_RAW` | 上料：料盘抓完、底盘要去传送带一时，申请放置毛坯。等到 `PLACE` 或 20 s 超时 |
| `APPLY_PICK_HALF` | 转运抓取不再发送。下料不用这条 |
| `APPLY_PLACE_HALF` | 转运：去传送带二的路上申请放置。等到 `PLACE` 或超时 |
| `APPLY_PICK_WELL` | 下料不再发送 |
| `PICK_UP_DONE` | 这次抓取结束（抓到、抓空、或申请超时没抓） |
| `PLACE_DONE` | 这次放置结束 |
| `DONE` | 整个任务完成（充电达到阈值也发这条） |
| `RAW_MATERIAL_EMPTY` | 上料开抓前数到的毛坯这次被拿光 |
| `WELL_DONE_MATERIAL_FULL` | 下料放下后成品盘左右都没有空孔 |

申请超时：**放置**不再等，直接放。传送带抓取不再申请。

### 1.3 只记在本机面板，不发给调度

`STANDBY`、`WORKING`、`GO_CHARGE`、`commuting`、`CHARGING`，以及 `ERR_MOTOR_LOST`、`ERR_MOTOR_DISABLE`、`ERR_GRIPPER_LOST`、`ERR_CAMERA`、`ERR_AGV_OBSTACLE`。

电机丢失、电机失能、夹爪丢失会停在原地等系统处理。`1101` / `1102` / `1201` 等网页回复，不回 AP14。其它失败回 home → AP14。传送带抓取和放置的取帧、二维码和检测失败都算视觉失败：先再拍一次，仍失败上报 `1201` 后停在原地。调度抓取只拍这一次，不再另做预看。

## 2. 视觉怎么决定动作

### 2.1 传送带抓取

整张头图跑 YOLO，检测框画在 `picture_debug/head/belt_yolo_det_*.jpg`。每个工件中心用深度变到**二维码坐标系**。不和抓取点做距离比较，也不再裁切 ROI。

抓取窗口（米，码系，写在 `kBeltGraspWin*`）：

- X：[-0.05, 0.05]
- Y：[0.10, 0.13]

窗口内 0 个：两手都不伸。1 个：只伸右手；右臂锁定时改伸左手。不少于 2 个：双手，先右后左。手臂仍走到 `grasp_offset`，不走到检测框中心。立件（class 0）和倒件（class 2）都算零件。重叠框 IoU ≥ 0.5 合成一个，不按框数相加。这一次不因为倒件停下。本地 `cycle` / `grasp_belt` 和调度用同一窗口。

夹爪报空之后再拍一张，只看同一窗口：

- 只剩倒件，或倒件置信度比叠在一起的立件高出 0.10 以上：和窗口里没料一样，上报 `1102`，原地等到网页点解决。已解决后再拍。哪只手没抓到就只补那只手：右手已经夹住时不松开、不动，只伸左手；右手自己没抓到时按新照片件数重抓，两个则先右后左。未解决就停在原地等下一条。
- 立件更高，或两者接近：当成还立着，在窗口内再抓一次。再抓仍空就按没抓到继续，不再循环。
- 窗口内没有零件：没抓到或被碰走，发 `PICK_UP_DONE`，按手里实际有没有件继续。

| 窗口内件数 | 动作 | 上报 |
|----------|------|------|
| 0 | 不伸手 | `1102` UnloadPointEmpty。已解决则再拍再抓；未解决则原地等下一条 |
| 1 | 只伸右手（右臂锁定则左手）。合爪后 **2 s** 底盘出发。这只手收回后发 `PICK_UP_DONE` | `PICK_UP_DONE` |
| ≥2 | 右手合爪成功后左手马上抓。转运和下料抓取都不申请。转运底盘等最后合爪的那只手后再过 **2 s** 去传送带二。下料同样在最后合爪 **2 s** 后去成品盘。左手收回后发 `PICK_UP_DONE`。整个任务的 `DONE` 要等该任务的放置结束 | `PICK_UP_DONE` |

窗口内没有零件，或空抓后再拍确认不是倒件、也不再抓：发 `PICK_UP_DONE`，按手里实际有没有件继续。倒件不上报新的错误码，用 `1102`。

### 2.2 传送带放置（上料和转运用）

这次要放的手，其放置点（码系 `offset`）与零件做最优匹配，门限 **±3 cm**。一个零件都配不上则允许放。配上了就不放，上报 `1101` LoadPortBlocked，手里有件原地待命。放置点仍是码加 `offset`，不改成检测框中心。

### 2.3 料盘

上料抓取：ArUco 定孔，YOLO 按 class 0（有料）选孔。抓完前看到的件数这次被拿光，就发 `RAW_MATERIAL_EMPTY`。

下料放置：ArUco 定孔，YOLO 按空孔（class 1）放到成品盘。放下后左右空孔都是 0，发 `WELL_DONE_MATERIAL_FULL`。

## 3. 总循环

1. 启动：home，去待命点（`standby_point` 或 AP14），以 home 姿态等任务。
2. 收到四个任务之一就执行。
3. 成功：发过该任务自己的 `DONE` 后，原地再听 20 s。20 s 内有下一条就连做，否则回 home → AP14。
4. 异常码发给调度后停住，等网页点已解决或未解决，**不回 AP14**：
   - `1101` 放置点 ±3 cm 内有零件，左右手都不放
   - `1102` 抓取窗口内没有零件，空抓后再拍判成倒件，或上料/转运放完后放置点 ±3 cm 内有倒件
   - `1201` 传送带视觉失败（取帧、二维码、检测）。先自动再拍一次，仍失败才上报。料盘二维码失败直接上报
   - 返回 true：不再申请，原地再拍一次，重做刚才的抓或放
   - 返回 false：停在当前站等下一条任务。这一等没有 20 s 之后回 AP14
5. 手里还有件的失败同样停在原地，不报完成，不回料架再抓。
6. 充电结束停在充电等待点（默认 AP12），不断开后改去 AP14。

---

## 4. 上料 `TASK_LOAD`

1. 去料架，头相机认料盘，按有料孔抓（可两只手）。抓取收手时底盘已经朝上料点走，同时发 `APPLY_PLACE_RAW`，等 `PLACE`。
2. 若开抓前的件数这次拿完，发 `RAW_MATERIAL_EMPTY`。
3. 两手都没抓到：任务失败返回，不去放。
4. 到传送带一。申请已允许就停稳后拍照放；超时则直接放。要放的那只手，放置点 ±3 cm 内必须没有零件。
5. 两手都收回准备位后拍一张。这次放过的放置点 ±3 cm 内倒件多于 0 个：上报 `1102`，原地等到网页点解决，已解决再拍，未解决不发完成。没有倒件才发 `PLACE_DONE` 和 `DONE`。停在传送带一。

料盘二维码失败：上报 `1201`。已解决则再拍；未解决则停在原地等下一条，不回 AP14。

---

## 5. 转运 `TASK_TRANSFER`

放置松手在基座 Z 再低 **5 mm**。抓取点就是 `conveyor.grasp_offset`，不再另加 +5 mm。

1. 去传送带一，摆到拍照姿态。
2. 拍一次，按 §2.1 看抓取窗口并伸手。没有料就报 `1102`，不回 AP14。已解决则再拍再抓，未解决就停在原地等下一条。
3. **不发** `APPLY_PICK_HALF`，不等 `PICK_HALF`。
4. 抓取准备姿态用 `conveyor.tcp`，抓取点用码 + `grasp_offset`，抓完收回 `conveyor.tcp`。
5. 空抓后再拍。倒件上报 `1102` 并原地等待，这时底盘还没出发。立件再抓一次；窗口里没有零件才按空抓继续。最后合爪成功的那只手闭爪 **2 s** 后底盘去传送带二。单手在该手收回后发 `PICK_UP_DONE`；双手在左手收回后发，不等底盘到站。抓到、确认没抓到都发 `PICK_UP_DONE`。倒件等待期间不发。
6. 手里没有件：跳过放置，仍发 `DONE`。
7. 手里有件：去传送带二的同时发 `APPLY_PLACE_HALF`，等 `PLACE`。超时直接放。
8. 传送带二放置点 ±3 cm 内没有零件才放。放完再拍一张，这次放过的放置点 ±3 cm 内有倒件就上报 `1102` 并原地等待，已解决再拍。没有倒件才发 `PLACE_DONE`，随后发 `DONE`。停在传送带二。

传送带二维码、取帧或检测失败：先再拍一次，仍失败上报 `1201`。已解决则再拍，未解决则原地待命，不发 `DONE`。

---

## 6. 下料 `TASK_UNLOAD`

抓取规则与转运相同（§2.1），站点换成传送带二，参数用 `conveyor2`。不发 `APPLY_PICK_WELL`。抓完收回的是料盘放置准备 `standby`。

1. 收到任务后去传送带二，摆到拍照姿态。
2. 拍一次，按 §2.1 决定伸哪只手。窗口内 0 个：不抓，报 `1102`，原地等指令。
3. 有件就直接抓。空抓后再拍：倒件上报 `1102` 并原地等待；立件再抓一次。最后合爪成功的手闭爪 **2 s** 后底盘去成品盘。确认没抓到才发 `PICK_UP_DONE`。
4. 手里没有件：不去成品盘，仍发 `DONE`。
5. 手里有件：到成品盘后真放置（张爪）。空孔用料盘 ArUco + 空孔类别。
6. 放下后若左右空孔都没有，发 `WELL_DONE_MATERIAL_FULL`。
7. 放置结束后才发 `DONE`。停在成品盘。中间不发 `DONE`。

料盘二维码失败且手里有件：上报 `1201`。未解决则原地待命，不发 `DONE`。

---

## 7. 充电 `CHARGE`

1. 本机记下准备去充电。整机 home，去待命点。
2. 手臂下垂，腰降到抓取高度，失能腰、臂、头（右臂锁定则跳过右臂）。
3. 底盘去充电点。
4. 电量达到 `charge_done_percent`（可热改）后发 `DONE`，断开充电继电器。
5. 重新使能。手臂回 `home_tcp`，腰高不动，底盘去充电等待点（默认 AP12）等下一条指令。

## 8. 信号对照（一张表）

| 步骤 | 机器人发出 | 调度应回 | 超时 20 s |
|------|------------|----------|-----------|
| 要任务 | 申请任务（点位空则先要站点） | `TASK_LOAD` / `TASK_TRANSFER` / `TASK_UNLOAD` / `CHARGE` | 一直等到任务或断线 |
| 上料放 | `APPLY_PLACE_RAW` | `PLACE` | 直接放 |
| 转运抓 | 不申请，直接抓 | — | 没料报 `1102`；抓完仍发 `PICK_UP_DONE` |
| 转运放 | `APPLY_PLACE_HALF` | `PLACE` | 直接放 |
| 下料抓 | 不申请，直接抓 | — | 没料报 `1102`；抓完仍发 `PICK_UP_DONE` |
| 抓完 | `PICK_UP_DONE` | 应答 | 库内重发 |
| 放完 | `PLACE_DONE` | 应答 | 库内重发 |
| 任务完 | `DONE` | 应答 | 库内重发 |
| 料架空 | `RAW_MATERIAL_EMPTY` | 应答 | 未连接先缓存 |
| 成品盘满 | `WELL_DONE_MATERIAL_FULL` | 应答 | 未连接先缓存 |
