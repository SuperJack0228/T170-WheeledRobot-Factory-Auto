## 修改后实际链路

1. 头相机在伸手前提供目标孔行列、料盘粗位姿和已占用孔；目标孔号在该次会话中固定。
2. TCP摆成放置姿态并进入下降后，手相机取RGB，按采集时刻的实测TCP确定相机位姿；不获取深度图，不检测ArUco，不依赖手相机看到二维码，也不调用YOLO框中心来代替孔心。
3. 用粗位姿和规则孔距预测可见邻孔区域，将各区域透视展开到盘面，再从孔边缘/橙色盘面孔环拟合几何中心。被遮挡的目标孔始终排除；占用孔只允许使用盘面橙色孔环，不能把抬高的金属零件边缘当孔口。
4. 当前xy_only=true，仍固定头相机给出的盘面高度和法向，只拟合盘面XY平移。多个邻孔应支持同一个平移，才推算目标孔在该帧的虚拟像素坐标。
5. 虚拟目标像素与正确放置时工件轴线的参考像素比较，经原像素映射/延迟补偿/PD控制修正TCP XY。确认对准并锁定目标后，按原流程下降至参考Z、松爪、撤离。

当前算法仍需要头相机粗位姿、孔距、手眼/相机参数支持孔号关联和透视展开。周期网格不能只挑最近圆就确定孔号。若盘面高度、法向或映射比例存在偏差，邻孔可能确实找到了，却不支持单一XY平移；这也是后续需要用实图和诊断区分的原因之一。移除二维码不等于消除这些模型误差。

## 新增诊断与检查

邻孔不够：tray_insufficient_visible_neighbors。

候选够但拟合失败：tray_neighbor_fit_rejected，reason后面携带shift_limit / insufficient_consensus / reprojection_gate、候选数量、共同支持数量、中位偏移、共识门限、重投影误差，以及每个rNcM候选的平面偏移(mm)。不通过修改速度/放宽丢失超时来掩盖没有有效观测。

定位source在失败时也设置为neighbor_xy或neighbor_geometry，避免日志空白。未增加下降存图；原显式存图开关保持。

离线用例覆盖：目标孔完全遮挡且没有标记时定位、可见标记不参与定位、只有标记而无邻孔时拒绝、透视/畸变、左右图旋转、相机运动、橙色孔环、已占用孔，以及明确的拟合失败诊断。人工渲染用例通过只能证明这些软件行为，不能证明真实反光/遮挡图像识别通过。

本轮未重写邻孔拟合模型。左手候选拟合失败仍需真实RGB帧与同次日志，或新增逐孔诊断确认后处理；不能宣称本轮已确保放置成功。
