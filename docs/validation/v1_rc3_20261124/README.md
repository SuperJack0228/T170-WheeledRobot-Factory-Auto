# rc.3 机床高度绑定验证

候选标签：`v1.0.0-rc.3`。参考为用户确认的机床 1.2：二维码平面离地 123.6 cm，腰高 0.63 m 时基座 Z 为 −0.29 m。信息码 550／551 对应 1.2／1.1，后续组每组递增两个码。

## 已执行

- 离线 Release 构建及主程序、任务、运动调用层编译检查通过。
- 完整 CTest 53/53 通过，见 `ctest.txt`。
- C++ 测试逐台校验十个高度与信息码、厘米转米、机床类型和腰高补偿方向。
- Python 使用生成的真实 ArUco 图像完成识别，554 对应 `YF-0005`／3.2；校验只见公共定位码、类型不符、多个同类目标及重复定位码的处理。
- 高度值改变可空闲热更新；信息码或类型改变要求重启已缓存的视觉引擎。
- 高度表与完整参数快照在同一配置事务中发布；测试覆盖暂存失败时保持旧值，以及再次重载运行快照不退回旧高度。
- 升级测试从缺少高度表和映射的旧档案迁移，补齐公共表并保留本机参数、二维码几何及相机配置；安装布局测试覆盖升级命令。
- C++ 加载器输出中所有既有运动控制参数与基线一致。新增高度表会按观测机床改变运行目标，例如 551／1.1 比原共同参考低 9 mm，属于预期行为变化。

完整绑定和参考腰高下的码平面 Z 见 `bindings_and_validation.json`。本次未构建新的 ARM64 交付包、未操作机器人，需在兼容 Linux 环境构建并现场验证各机床抓放。原有工具／工艺 Z 偏置仍然叠加，未擅自删除历史偏置。

配置与部署说明见 [机床信息码与高度绑定](../../deployment/CONVEYOR_HEIGHT_BINDINGS.md)。
