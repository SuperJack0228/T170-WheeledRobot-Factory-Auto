## 1. 概述

系统采用“头相机粗定位、手相机局部修正”的分层视觉控制结构。头相机负责识别工位、选择工件或目标孔，并生成名义操作位姿；机械臂接近目标后，由手相机提供图像观测，在基本固定的末端姿态下连续修正基座坐标系内的 X、Y 位置。Z 轴终点由工位配置和名义操作点确定，下降速度根据平面对齐进度协调。

本实现属于面向固定姿态操作的二维图像视觉伺服（Image-Based Visual Servoing，IBVS）工程链路：图像误差经高度相关雅可比转换为平面剩余位移，再由受约束的位置执行内环跟踪；未采用图像特征直接控制全部六维相机速度的通用控制形式。

控制链路由高度相关图像映射、采集时刻运动补偿、平面 PD 控制、预测制动、参考领先量约束及局部运动学求解组成。视觉观测与运动执行采用不同线程，视觉线程不直接发送关节指令。每只手在局部伺服阶段由对应运动执行者统一维护参考位置和关节命令。

手相机使用 RGB 图像，不使用深度图构造抓放目标。几何映射仍使用相机内参、手眼关系及特征平面先验估计成像距离，因此系统并未消除对几何参数的依赖。几何误差、工具安装变化和工件夹持偏心仍会影响最终物理对准精度。

## 2. 应用范围与边界

| 作业 | 手相机观测 | 主要控制策略 |
| --- | --- | --- |
| 料盘抓取 | 手部检测模型输出的目标工件框中心，类别 0 | 连续 XY 修正、下降协调、近端目标锁定、合爪 |
| 传送带抓取 | 手部检测模型输出的工件框中心，类别 0 | 复用抓取控制器；单手抓取、抬离后放行另一只手 |
| 料盘放置 | 邻孔和 ArUco 标记推算的指定孔虚拟投影 | 可见区对准、目标锁定、遮挡末段下降、张爪 |
| 传送带放置 | 当前通用分支按类别 1 调用手部检测；无有效料盘目标时不进入邻孔定位 | 已接入伺服调用，但需要独立的特征定义及现场验收 |

当前 YAML 中 `belt_grasp_enabled`、`belt_place_enabled` 和 `tray_place.enabled` 均为 `true`。开关开启表示调用相应实现，不构成该场景已完成验收的证据。尤其是无孔传送带上的放置，不能直接将类别 1 的空孔观测解释为有效放置基准。

料盘放置以工件相对夹爪的位置基本固定为前提，未实现夹持偏心、滑移或倾斜的在线估计。系统未引入腕部六维力反馈、接触搜索或力控插入。

## 3. 软件结构与数据流

```text
头相机识别、任务选目标
        ↓ 名义目标 C；料盘放置另携带目标行列及盘面先验
SDK 接近轨迹 → 接近末段交接
        ↓
运动执行器 ← 最新有效观测 ← 手相机 RGB / 检测或邻孔定位
    │                           ↑
    ├─ 实测关节 → FK → 状态历史 ──┘ 采集时刻相机位姿
    ├─ 图像映射 → 目标估计 → PD / 制动 / Z 速度协调
    ├─ 局部位姿求解 → 关节约束 → 下发
    └─ 完成保位 → 夹爪反馈确认 → 竖直抬升 → 单独规划返回
```

### 3.2 双速率执行

局部运动循环配置周期为 10 ms。每轮读取实测关节，计算 FK 和速度，再消费最新待处理观测；没有新图像时仍根据已估计目标和当前运动状态更新控制输出。SDK 接近轨迹和最终保位的名义发送周期为 5 ms。

视觉侧使用单个轮询线程依次服务左右手，每次获得处理机会后再取帧。双手共享推理资源，不采用两路独立并行推理。每手观测缓存仅保留待消费的最新观测，不累积一串尚未执行的视觉位移。

上述周期为软件调度配置。实际周期受到关节回读、运动学计算、通信和操作系统调度影响，不能等同于固定频率的硬实时执行。

## 4. 坐标系、时间与图像约定

### 4.1 坐标与单位

- 控制位置在当前机械臂基座坐标系表达，长度单位为 m；基座 Z 向上为正。
- 关节角和旋转约束使用 rad，图像坐标使用 px。
- 图像原点位于左上角，u 向右、v 向下。左手图像旋转 180°，相机内参与畸变参数同步调整。
- 名义最终点记为 C，最终名义 TCP 高度记为 `z_C`；当前相对高度为 `h = z_TCP - z_C`。
- 参考像素表示在指定参考高度、正确工具对准关系下的特征投影，不代表图像中心，也不等同于相机光轴。

手相机位姿由采集时 TCP 实测位姿和固定 TCP—相机变换组成：

```text
T_base_camera(t_c) = T_base_tcp(t_c) · T_tcp_camera
```

其中 `T_tcp_camera` 根据已加载的手眼变换及工具变换建立。工具长度或安装方式改变后需要复核该关系。

### 4.2 状态历史与时间关联

关节回读时间取读取开始和结束的中点；其不确定度包含半个读取耗时及 `feedback_age_budget_s`。位置和关节角采用线性插值，旋转采用四元数球面插值。状态历史最多保存 600 个样本或约 3 s 数据。

图像记录设备时间、统一单调时间、时间来源及不确定度。相机支持全局时间映射，并在不可用时使用带帧周期不确定度的设备时钟回退。执行器只在历史覆盖图像采集时刻、且相邻状态间隔不超过 `max_state_gap_s` 时使用该观测，不用命令位姿外推替代实测状态。

实测平移速度由相邻 FK 位置差分得到，并采用：

```text
v_k = 0.4 · v_raw,k + 0.6 · v_(k-1)
```

该速度用于控制阻尼和完成判定，仍受编码器、回读时序和运动学模型噪声影响。

## 5. 图像误差到平面位移的映射

令观测像素为 `s = [u, v]ᵀ`，当前高度对应的参考像素为 `s*(h)`，定义：

```text
e_px = s - s*(h)
J_xy(h) = ∂[u,v] / ∂[x_base,y_base]        单位 px/m
Δp_xy = -J_xy(h)⁺ · e_px                 单位 m
```

因此，固定的“100 px 对应若干 cm”不适用于整个下降行程。换算由当前成像距离、焦距、相机方向或实测映射表决定。

### 5.1 几何模式 `geometry`

几何模式利用针孔投影、手眼关系、采集时相机位姿以及水平特征平面计算参考像素和局部图像雅可比。

特征平面高度为：

```text
z_feature = z_C + feature_z_offset_m
```

以观测像素构造相机射线 `r = [(u-cx)/fx, (v-cy)/fy, 1]ᵀ`，相机原点为 `o`，相机到基座旋转为 R，则成像距离为：

```text
Z_c = (z_feature - o_z) / (R · r)_z
```

这里的 `Z_c` 是射线与已知平面的交点深度估计，未读取深度传感器。参考像素同样依据参考高度的成像关系投影到当前高度，避免将最终高度示教像素直接用于整个下降过程。

实现检查射线与平面的夹角、深度范围、参考像素是否在画面内，以及雅可比条件数。当前最小奇异值要求为 1 px/m，条件数上限为 30。映射无效时拒绝观测，不用固定深度补值。

映射核心采用局部针孔近似；料盘邻孔模块另行进行去畸变和重投影。几何模式不是自动标定算法，不能据此认定原有手眼误差已经被永久辨识或消除。

### 5.2 实测表模式 `table`

实测表按 `height_m` 保存参考像素和 2×2 雅可比 `jacobian_px_per_m`，在相邻高度节点间线性插值。高度超出节点范围、矩阵退化或节点非法时拒绝使用，不进行表外外推。

当前四组 profile 均为 `geometry`，仓库未配置有效的实测雅可比表。左右手、抓取和放置分别保留独立 profile。没有显式填写 `reference_px` 时，继承相机配置中的参考像素：左手 `[598,458]`，右手 `[702,458]`。

放置参考像素应对应夹持工件轴线与目标孔正确对准时的投影。当前放置 profile 沿用上述像素，仍需独立现场确认，不能仅由抓取成功推定放置参考有效。

## 6. 运动延迟补偿与观测筛选

图像在 `t_c` 采集，完成处理和被控制器使用的时刻晚于 `t_c`。控制器先在采集时刻建立目标位置：

```text
p_candidate = p_xy(t_c) + Δp_xy(t_c)
p_goal ← p_goal + α · (p_candidate - p_goal)
e_m(t) = p_goal - p_xy(t)
```

首个有效候选直接建立目标，后续采用 `α = 0.65` 滤波。控制器使用当前实测位置计算剩余误差，图像采集后已经完成的运动因此被扣除。该方法面向本项目中的静止工件或静止孔位，没有实现运动目标速度预测。

观测接纳条件包括：

1. 会话、帧号及采集时间顺序有效；运动阶段仍接收视觉输入。
2. 图像年龄与时间不确定度之和不超过 0.35 s，时钟不确定度不超过 0.12 s。
3. 置信度不低于 0.45；普通检测还需满足类别及像素关联窗口。
4. 目标相对名义 XY 的总修正量不超过 35 mm。
5. 已建立目标时，新候选与当前估计的差不超过 12 mm。
6. 采集时状态插值及图像映射有效。

普通抓取初次关联半径为 180 px，锁定后使用 100 px 的跟踪半径。匹配限定在目标类别内，并围绕预计投影或上一有效观测选择候选。该策略是局部关联，不包含通用多目标身份跟踪。

## 7. 平面 PD 控制、制动与参考约束

### 7.1 PD 控制

控制器首先计算：

```text
v_PD = Kp · e_m - Kd · v_xy,measured
```

当前 `Kp = 1.5 s⁻¹`，`Kd = 0.2`。D 项使用经过滤波的实际 TCP 平移速度，不直接差分低频图像误差。系统未启用积分项。

实际输出进一步沿“当前参考位置指向目标”的方向投影，只保留朝向目标的非负分量，并施加速度、加速度和制动上限。误差进入 2 mm 精对齐范围后，期望平面速度置零，已有速度仍按加速度约束衰减。

### 7.2 预测制动

在可用距离 d、减速度 a 和延迟预算 τ 下，制动速度上限采用：

```text
v_brake(d,a,τ) = √((aτ)² + 2ad) - aτ
```

该上限对应 `vτ + v²/(2a) ≤ d`。平面误差侧的可用距离扣除 `0.25 · xy_tolerance_m` 和 `model_uncertainty_m`，延迟预算包含配置制动延迟及最近观测的时间不确定度；参考剩余距离另计算一个制动上限。最终限速取各上限与 `max_xy_speed_m_s` 的最小值。

这是一维保守制动包络，结合局部方向用于平面控制，不是 MPC 优化器，也不是对完整机械系统稳定性的形式化证明。

### 7.3 限加速度与参考领先约束

当前 XY 最大速度为 40 mm/s，XY 最大加速度为 0.20 m/s²，Z 最大加速度为 0.25 m/s²。参考每轮由受限速度积分更新，并限制跨越目标的增量。

参考与实际位置间距达到 12 mm 后逐步减小 XY 和 Z 推进速度；达到 25 mm 时限制参考继续向外推进。参考不会直接跳回当前实测位置。运动求解只执行了部分增量时，将实际接受的参考和速度反馈给控制器，防止未执行的增量继续累积。

## 8. 下降速度协调与状态机

### 8.1 剩余时间协调

控制器以误差距离、速度饱和、比例收敛时间、当前平面速度、图像年龄和时间余量估计对齐时间：

```text
T_align = max((d-ε)₊/v_xy,max, ln(max(1,d/ε))·(1+Kd)/Kp)
          + ||v_xy||/a_xy,max + age + time_margin
T_available = remaining_Z_travel / nominal_descent_speed
```

未锁定且尚未精对齐时，下降速度受 `remaining_Z_travel / T_align` 限制，并结合垂直制动距离减速。平面对齐越慢，可用下降行程越少，Z 推进速度越低。

当前名义下降速度读取 `head_grasp.descend_vel_m_s = 0.10 m/s`，末段速度上限为 `commit_speed_m_s = 0.060 m/s`。它们是上限；实际速度还受制动、对齐时间、关节约束和驱动跟随影响。Z 终点未由手相机重新估计。

### 8.2 执行状态

| 状态 | 进入条件或行为 |
| --- | --- |
| `Acquiring` | 等待首个有效目标；首帧前仅允许有界下降，配置行程上限 20 mm |
| `Descending` | 接收有效观测，连续修正 XY 并协调下降 |
| `Hold` | 已有目标但观测过期，且不满足近端抓取继续条件；停止期望推进并等待新观测 |
| `Commit` | 锁定目标估计、停止接收新图像修正；继续跟踪固定 XY 并完成末段下降 |
| `Settling` | 运动参考停止，等待实际位置和速度满足结束条件 |
| `Done` | 完成条件持续满足，保持最后合法关节参考 |
| `Failed` | 故障、超时或约束持续不满足，退出局部伺服并向上层返回原因 |

`Commit` 锁定的是目标估计，不是立即停止所有 XY 控制；实际末端仍需收敛到已锁定目标。枚举中另保留 `Aligning`，当前主控制分支未将其作为独立持续阶段。

### 8.3 抓取结束条件

正常抓取优先通过多个新观测进入 2 mm 精对齐范围，并使用 3 mm 退出迟滞。实际平面误差和速度满足条件、且 TCP 进入 C 上方 30 mm 内时，可提前锁定目标。

未能精对齐时，未锁定参考最多下降到 C 上方 8 mm。在该区域等待至少 0.35 s，且至少两个连续有效观测、平面剩余误差不超过 6 mm、平面速度不超过 8 mm/s 时，可按抓取容差进入末段。

当前实现还包含近端丢目标继续分支：已经建立过有效目标、观测过期、实际 TCP 进入 C 上方 30 mm 内、相对最后目标的剩余误差不超过 6 mm，且未越过高度容差时，允许锁定最后目标并完成抓取。该分支不重新要求正常分支的连续新帧确认；若此前已超过 1.5 s 丢失超时，则先进入失败状态，不能继续。该策略仅适用于抓取，不用于未锁定的料盘放置。

抓取参考停止在 `z_C + 2 mm`。结束判定允许编码器 FK 高度位于 `[z_C - 1 mm, z_C + 6 mm]`，其中下侧 1 mm 是反馈容差，不是向 C 下方生成参考。实际 XY 误差不超过 6 mm，XY 和 Z 速度分别不超过 8 mm/s，参考停止且条件持续 40 ms 后进入 `Done`。

上述距离均是当前运动学和观测模型中的距离，不等同于独立量具测得的物理定位精度。

## 9. 料盘放置：邻孔几何与遮挡处理

### 9.1 目标身份和盘面先验

头相机选定空孔后，将行、列、盘面几何、占用状态及盘面变换传入局部放置会话。手相机始终求解该指定孔的投影，不以最近邻孔替代目标孔。腰部前伸和基座变换需同步作用于目标及盘面先验。

### 9.2 邻孔中心提取

目标孔被夹爪或工件遮挡时，使用可见邻孔和标记提供约束：

1. 对 RGB 图像去畸变，依据盘面先验建立透视映射。
2. 将邻孔局部 ROI 校正到盘面尺度，再检测灰度轮廓和橙色环轮廓。
3. 拟合环形轮廓并检查尺寸、轴比、圆周残差、关联距离和角度覆盖。
4. 已占用孔只允许合格的橙色盘面环参与，不使用凸起工件的灰度金属边缘。
5. 目标孔始终排除在邻孔拟合之外；标记重复 ID 通过先验位置和角点顺序区分。

在盘面校正后提取中心，避免直接使用原图检测框中心或将透视椭圆中心当作真实圆心投影。当前圆周覆盖划分为 16 个方向区间，要求至少覆盖 12 个区间。

### 9.3 平面更新与虚拟孔心

当前 `xy_only=true`，保留盘面高度和姿态先验，只估计基座平面平移，不逐帧自由更新深度和倾角。无可用标记时至少需要两个可靠邻孔；几何不一致或重投影误差过大时不提交观测。

`xy_only=false` 保留完整几何分支：具有足够非共线对应点时，使用 RANSAC 单应性筛选及带先验的刚体位姿求解；完整估计失败而邻孔平移一致时，可退回平移更新。完整分支不代表当前配置正在采用该模式。

指定孔经更新后的盘面变换投影到采集时相机，并重新施加畸变，输出与控制器一致的原图像素坐标。几何来源记录为 `neighbor_xy`、`marker_xy` 等。图像处理失败时不以旧像素配新时间戳提交。

### 9.4 可见区锁定与末段下降

当前料盘放置在 C 上方 65 mm 内允许锁定，要求至少三个连续有效观测满足 4 mm 误差范围，目标估计变化不超过 2.5 mm，并满足平面速度不超过 10 mm/s 等条件。尚未锁定时，参考下降边界为 C 上方 50 mm；系统在该可见区域继续修正或等待，不能因目标孔被遮挡直接盲放。

进入 `Commit` 后不再依赖新图像，沿固定目标完成剩余下降。参考停止在 C 上方 1 mm；反馈高度范围为 `[z_C - 1 mm, z_C + 5 mm]`，平面误差不超过 4 mm，XY 和 Z 速度分别不超过 10 mm/s，稳定条件持续 40 ms 后结束。

65/50 mm 为当前安装和场景的配置值，应根据有效可见区确定。虚拟孔投影的稳定性只说明几何估计一致，不能单独证明夹持工件轴线已物理对准。

## 10. 局部求解、夹爪与撤离交接

### 10.1 固定姿态局部求解

局部求解以最近合法关节命令为种子，通过原 SDK 的 FK 建立 6×7 有限差分雅可比，采用阻尼最小二乘更新关节角。位置与旋转误差同时参与，旋转使用权重 0.12；每次求解最多迭代 6 次，差分步长为 `1e-5 rad`。

运动执行器对每轮笛卡尔增量最多进行 8 次逐半缩放尝试，检查关节速度、加速度、总偏离、FK 高度及求解残差。当前残差上限为 0.6 mm 和 0.5°，关节速度上限为 0.45 rad/s，加速度上限为 2 rad/s²。连续 5 次求解失败后退出。交接过程中姿态向目标连续插值，不在单周期内强制跳变。

当前 `enforce_sdk_joint_limits=false`，保留现场 SDK 限位检查旁路；局部关节相对交接起点的偏离限制为 0.70 rad。相对偏离、速度、双手 TCP 距离和跟随检查仍存在，但不替代真实绝对关节限位及完整连杆碰撞检查。

### 10.2 接近与保位

B 点是 SDK 接近轨迹的引导位置。接近减速末段同时满足参考距离、姿态、笛卡尔速度和关节速度条件时提前交接；否则播放至接近段末端再交接。实现保留末端减速的兜底路径，不保证每次都以非零速度通过 B 附近。

伺服 `Done` 后保持最后合法关节指令，不再额外执行一次 IK。夹爪动作前重新读取实际位姿，检查对应抓／放容差、姿态及故障状态。最终保位持续到后续轨迹取得该手命令所有权。

保位发送与接管使用同一把每手互斥锁，锁覆盖整组七关节发送。接管返回后，旧保位线程不能再发送缓存的抓取位置，避免上抬时被旧命令拉回。

### 10.3 抓放后撤离

抓取后采用两个独立阶段：保持夹取姿态竖直抬升，再保持抬升位置并规划返回。返回规划失败不会阻止第一阶段已经能够执行的抬升。当前抓取名义抬升量为 80 mm，抬升和返回规划速度上限均为 0.40 m/s，受原有工作高度和 SDK 轨迹限制。

料盘抓取在本轮所需手臂均持件、实际抬离至少 15 mm 等条件成立后，可并行纯 Z 升腰；尚有抓取目标待执行、料盘放置及其他不满足条件的流程不触发该并行升腰。

传送带通常先右手后左手。第一只手合爪并启动撤离后，第二只手等待第一只手实测竖直抬离 50 mm，再开始进入抓取区域，与前手剩余撤离过程重叠。超时为 4 s；放行依据反馈净抬升量，不以收手线程启动代替实际撤离。

料盘放置在张爪反馈确认后撤离，未确认侧保留持件状态。夹爪编码器确认张开不等于工件落孔确认；当前未增加独立落位传感器。

## 12. 日志与故障诊断

### 12.1 运行记录

伺服日志写入公共日志根目录下的 `visual_servo/servo_*.csv`，默认位于工程 `logs/visual_servo`。CSV 由有界队列异步写入；日志创建失败或写入器异常会影响当前视觉动作的可执行状态。

每个会话记录参数快照、构建 Git SHA、dirty 状态及源码／配置摘要，并备份磁盘上的机械臂模型。料盘放置另记录目标行列、初始盘面变换及料盘配置副本。带 `on_disk` 的文件表示磁盘副本，不证明底层 SDK 内存中的模型内容。

| 记录组 | 主要字段或事件 | 诊断用途 |
| --- | --- | --- |
| 观测 | `capture_s`、`grab_ms`、`infer_ms`、时间不确定度、`observation` 原因 | 区分取帧、推理、过期和关联失败 |
| 映射 | 参考像素、像素误差、雅可比、成像距离、条件数 | 排查符号、尺度、高度和几何退化 |
| 控制 | 实际位置／速度、目标、参考、`alignment_time_s`、`available_time_s` | 分析超调、速度协调及参考领先 |
| 求解 | `applied_scale`、`solver_reason`、残差、关节领先 | 判断控制输出是否被运动约束缩小或拒绝 |
| 料盘 | `vision_source`、行列、邻孔数、重投影、轮廓拒绝计数、`place_locked` | 排查孔位身份、可见性和锁定条件 |
| 夹爪 | `gripper_gate`、`gripper_start`、`gripper_end`、`gripper_check` | 区分对准完成、执行夹爪及反馈确认 |
| 撤离 | `lift_*`、`return_*`、`peer_clearance`、`waist_rise_*` | 区分规划、实际抬离、返回及并行协调 |
| 异常回读 | `feedback_step`、实际关节、FK、读取耗时 | 排查高度突跳与反馈／发送时序 |

放置阶段的 `infer_ms` 表示几何处理及相关等待时间，不表示 YOLO 推理时间。进入锁定末段后停止采纳新视觉，最后观测年龄继续增长属于预期行为。

### 12.2 典型退出条件

- 始终没有有效观测或未锁定时目标持续丢失。
- 观测时间不确定、无采集时状态、雅可比退化或总修正范围超限。
- 参考跟随或姿态异常持续不收敛；当前执行器允许仍在缩小的交接跟随滞后，并保留约 2 s 的追赶时限。
- 连续局部求解失败、周期异常、双手 TCP 距离不足、CAN 故障或外部中止。
- 夹爪前实测位姿离开允许范围、张爪反馈未确认、抬升或返回执行失败。

分析时应同时使用 `session`、`hand`、`task_tag` 和首个失败原因。图像误差收敛但末端仍有固定偏差时，需检查参考像素、工具关系及实际工件轴线；不能仅通过提高控制增益处理静态基准误差。

## 13. 验证状态与部署复现

既有现场反馈表明，抓取视觉修正已能执行，传送带抓取表现可用；料盘抓取曾出现目标丢失和撤离问题，料盘放置此前未成功。11 月 3 日针对上述问题的两阶段撤离、近端处理及料盘几何改动，在本版文档编制时尚无新的完整现场验收记录。

第一步模块化整理后，14 项离线检查通过，覆盖控制、运行器、轨迹交接、双手放行、抓取结束、配置、料盘几何及包／模块边界。相关配置及算法主体已与整理前版本核对。离线几何和运动适配测试不代表真实 SDK、相机或机器人定位精度。

完整机器人构建需要匹配的 Linux／ARM64 SDK、RealSense、Python 推理环境及实际模型资源。机器人端构建入口为：

```sh
cmake -S . -B build_robot
cmake --build build_robot -j4
./build_robot/t170_factory 2>&1 | tee startup.log
```

会话结束后可汇总已有 CSV：

```sh
python3 tools/analyze_visual_servo.py logs/visual_servo --json servo_summary.json
```

现场验收应分别记录料盘抓取、传送带抓取、料盘放置的成功率、局部伺服耗时、有效观测间隔、结束残差、夹爪反馈和撤离结果。料盘放置需覆盖不同位置及占用率，独立核对目标孔身份和工件实际落位。当前系统尚未实现自动手眼标定、自动实测雅可比辨识或跨设备免调部署。
