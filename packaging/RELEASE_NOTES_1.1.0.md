# T170 Factory 1.1.0

在 V1.0.0 基础上更新手相机坐标适配、抓放运动、维护调试和多机器人操作，支持 T170C V2 的 3 kg／5 kg 配置。

当前为候选发布说明。先在 No.120 源码联调，通过后再冻结标签、构建和发布。

## 主要更新

- 修正默认手眼的父坐标声明，沿用已验证的旧法兰兼容变换；标准图像方向为左手原图、右手旋转 180°，No.124 保留独立安装配置。
- 料盘抓取、放置和传送带目标复用本机示教 XY；关闭手相机伺服时仍加载示教补偿。传送带伺服仅修正剩余误差，避免重复叠加。
- 优化伸手、抬升和收手的轨迹计时与动态约束，补充规划／实际速度日志。保留末端操作阶段的独立闭环约束。
- 料盘抓取前核对夹爪准备开度；已持件手保持夹紧。
- 网页支持多机器人切换、实际身份核验及代理访问；维护模式可手动进入／退出调度，生产启动入口保留自动进入调度。
- 修复异常待命超时后阻塞等待收信线程的问题；下料必须确认原持件手全部放下后才发送任务完成，空孔不足、部分放置及抓空不再误报完成。
- 适配调度 SDK 1.12 的文字异常接口，区分重试、跳过本次任务、下线和空返回；地图初始化、夹爪掉线及充电路径统一传递操作结果，中止请求不被迟到的重试覆盖。
- 本机网页令牌持久化；启动终端打印连接摘要。源码调试日志按日期写入 field_logs，运行包日志保留在状态目录。
- 保留五组机床站点选择和二维码高度绑定；传送带抓取计数窗口更新为码系 X ∈ [−0.08, 0.10] m、Y ∈ [0.09, 0.14] m。

## 升级与配置

运行包内提供可编辑的 config/。升级可从旧运行包、持久工作区或当前源码目录导入本机配置，保留快捷参数、任务标定、相机序列号和网页令牌，自动备份；校验失败则恢复目标目录。

对与原始 CAD 矩阵完全匹配、仍错误声明为 urdf_wrist 的共享手眼，仅修正父坐标声明；不替换实测矩阵，不重写任务标定指纹。旧任务参考若与修复后的手眼不匹配，升级校验会拒绝导入并恢复，需处理该参考后再迁移。

已有一次性偏置迁移记录的机器人不会再次清零或覆盖现场调参。共享 YAML 仍以导入配置为准；这次迁移不会强制重置其余控制参数。

## 交付和验证边界

- 交付：t170-factory-1.1.0-Linux-架构.tar.gz 及对应 SHA256；包含 release.json 和 environment.lock.json。
- No.120 的主要动作流程已由现场测试反馈基本跑通。已有日志同时包含成功、抓空、伺服失败和取消记录，不代表连续无人作业成功率测试。
- 离线回归覆盖运动控制、参数加载、抓放技能、网页、调度接口契约以及安装升级；具体结果见本次发布检查记录。
- 新版调度尚未完成实机联调。使用现有维护入口完成任务接收、执行反馈和退出调度检查后，再投入自动运行。
- Linux 原生链接及随包动态库检查在目标兼容主机构建时执行；Mac 离线检查不替代该步骤。
