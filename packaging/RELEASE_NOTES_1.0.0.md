# T170 Factory 1.0.0

T170C V2 工厂上下料首个正式运行包，支持 3 kg 和 5 kg 配置。生产模式接收调度任务，维护模式提供单步动作、标定及网页调试。

## 功能范围

- 料盘抓取、料盘放置及传送带抓取使用当前手相机 RGB 视觉伺服链路。
- 模型、机器人身份、相机与工具配置分层管理；常调参数集中于本机 quick_params.yaml。
- 实际配置目录随运行包提供，网页保存与手工修改使用同一来源。
- 五组机床维护站点可在网页选择；机床信息码与实测高度独立绑定，生产作业点由调度下发。
- 提供新机器人建档、统一参数应用、旧配置导入及升级回滚机制。
- 清理旧的一次性手相机三维修正与转运额外下压；统一本次确认的抓放偏置。

## 交付文件

- t170-factory-1.0.0-Linux-架构.tar.gz
- 对应 .tar.gz.sha256

运行包包含可执行程序、随包动态库、Python 与网页资源、在用权重和配置模板。本机抓放任务标定不随通用包分发；部署时按机器人编号建立。

## 环境与验证

构建与部署使用匹配的 Linux 架构、Ti5 设备／调度 SDK 以及 human_interaction_env 视觉环境。release.json 记录提交与架构，environment.lock.json 记录构建环境与依赖。

本地离线编译、54 项回归检查以及网页机床组交互检查已完成。Linux 原生链接和运行依赖由构建脚本检查；本批参数与维护站点变更的真机回归在交付验证中执行。

## 部署

首次部署：解压运行包 → 建立本机档案 → 启动维护与网页 → 建立本机抓放参考 → 验证任务 → 启动生产模式。

已有 rc.3 机器人：保留旧目录，执行 deploy/upgrade_robot.sh --from-workspace 旧工作区目录。升级会执行已确认的一次性偏置清理及维护站点迁移，后续现场调参保留。具体操作见包内 docs/V1_RELEASE_AND_FIRST_DEPLOYMENT.md 和 docs/PACKAGE_UPGRADE.md。
